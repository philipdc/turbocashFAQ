# TurboCASH FAQ

A comprehensive, community-maintained FAQ system for TurboCASH accounting software, optimized for both human readers and Large Language Models (LLMs).

## 📖 About

This repository contains self-standing web pages with semantic markup (Schema.org) that describe typical problems in TurboCASH and provide detailed solutions. Each FAQ is designed to be:

- **Self-contained**: Complete HTML pages that work standalone
- **GitHub-readable**: Viewable directly on GitHub or any web browser
- **LLM-optimized**: Structured with semantic markup for easy parsing by AI assistants
- **Community-driven**: Open for contributions via pull requests

## 🚀 Quick Start

### View FAQs

- **Online**: Visit the [GitHub Pages site](https://philipdc.github.io/turbocashFAQ/) (if enabled)
- **Locally**: Clone the repository and open `index.html` in your browser
- **Direct**: Browse the `faqs/` directory and open any HTML file

- [Installation & Setup](faqs/) - Getting TurboCASH up and running
- [Common Problems](faqs/) - Troubleshooting frequent issues
- [Features & Usage](faqs/) - How to use TurboCASH features
- [Performance & Troubleshooting](faqs/) - Advanced problem-solving

## 🤝 Contributing

We welcome contributions from the community! Whether you're fixing a typo, improving an existing FAQ, or adding a new one, your help is appreciated.

### How to Contribute

1. **Fork** this repository
2. **Create** a new branch for your changes
3. **Add or edit** FAQ pages following our guidelines
4. **Test** your changes locally
5. **Submit** a pull request

📖 Read the detailed [Contributing Guide](CONTRIBUTING.md) for complete instructions, templates, and style guidelines.

### Quick Contribution Checklist

- ✅ Use the provided HTML template
- ✅ Include Schema.org semantic markup
- ✅ Follow naming conventions (lowercase, hyphen-separated)
- ✅ Update `index.html` with your new FAQ
- ✅ Test in multiple browsers
- ✅ Validate HTML and semantic markup
- ✅ Write clear, concise content
- ✅ Include code examples where applicable
