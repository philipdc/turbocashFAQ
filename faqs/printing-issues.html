How do I fix printing issues in TurboCASH?

Last updated: November 17, 2025 | Category: Common Problems

Overview

Printing problems are common in accounting software and can affect invoices, reports, and statements. This guide covers the most frequent printing issues and their solutions.

Common Printing Problems

1. Invoices or Reports Print Blank

Symptoms:
  • Print preview shows content but printed page is blank
  • Only headers/footers print
  • Partial content appears on printed page
Solutions:
  1. Update Printer Drivers
    • Visit printer manufacturer's website
    • Download latest drivers for your model and Windows version
    • Uninstall old drivers before installing new ones
  2. Check Print as Image Option
    • In print dialog, click "Advanced"
    • Enable "Print as Image" or similar option
    • This often resolves driver compatibility issues
  3. Try Different Printer
    • Test with PDF printer (Microsoft Print to PDF)
    • If PDF works, issue is with physical printer driver

2. Formatting Issues / Text Cut Off

Symptoms:
  • Text extends beyond page margins
  • Columns misaligned
  • Content overlaps
  • Wrong font sizes
Solutions:

Adjust Page Setup:

  1. Go to File → Page Setup
  2. Verify paper size (A4, Letter, etc.)
  3. Check margins: 
    Top: 0.5 inch (1.27 cm)
Bottom: 0.5 inch (1.27 cm)
Left: 0.75 inch (1.9 cm)
Right: 0.75 inch (1.9 cm)
  4. Set orientation (Portrait/Landscape)

Modify Report Template:

  • Go to Tools → Report Designer
  • Open the problematic report template
  • Adjust column widths and field positions
  • Test with Print Preview before saving

3. Printer Not Found / Connection Error

Symptoms:
  • "Printer not found" error
  • Selected printer doesn't appear in list
  • Print job stuck in queue
Solutions:

Windows Printer Troubleshooting:

  1. Open Control Panel → Devices and Printers
  2. Verify printer shows as "Ready" (not "Offline")
  3. Right-click printer → Set as Default Printer
  4. Check printer cable/network connection
  5. Restart Print Spooler service: 
    1. Press Win + R, type: services.msc
2. Find "Print Spooler"
3. Right-click → Restart

Clear Print Queue:

  1. Open Control Panel → Devices and Printers
  2. Double-click your printer
  3. Click Printer → Cancel All Documents
  4. If stuck, restart Print Spooler service (see above)

4. Invoice Logo Doesn't Print

Solutions:
  1. Check Logo File:
    • Ensure logo file exists in correct location
    • Recommended formats: PNG, JPG (avoid BMP)
    • Optimal size: 300x100 pixels or smaller
    • File size: Under 500 KB
  2. Verify Template Settings:
    • Tools → Invoice Templates
    • Edit template → Check logo path
    • Ensure "Print Logo" option is enabled
  3. Re-upload Logo:
    • Company Settings → Logo
    • Remove existing logo
    • Upload new logo file
    • Test print preview

5. Slow Printing / Performance Issues

Solutions:
  • Reduce Report Complexity:
    • Limit date ranges for large reports
    • Remove unnecessary columns
    • Disable images/graphics if not needed
  • Printer Settings:
    • Lower print quality for drafts (600 DPI → 300 DPI)
    • Disable "High Quality" or "Best" mode
    • Use printer's "Draft" or "Fast" mode
  • Network Printers:
    • Check network connection speed
    • Consider installing printer drivers locally
    • Update printer firmware

Printer Configuration Best Practices

Setting Default Printer in TurboCASH

  1. Go to Tools → Options → Printing
  2. Select default printer for:
    • Invoices
    • Reports
    • Statements
  3. Set default paper size for each document type
  4. Configure number of copies
  5. Save settings

Creating Custom Print Templates

Steps:
  1. Tools → Report Designer
  2. Select report type (Invoice, Statement, etc.)
  3. Click "New Template" or edit existing
  4. Adjust layout, fonts, colors
  5. Add/remove fields as needed
  6. Use Print Preview extensively while editing
  7. Save template with descriptive name
  8. Set as default if desired

Testing Print Setup

Before printing important documents:

  1. Use Print Preview to verify layout
  2. Print a test page to draft/recycled paper
  3. Check all fields are populated correctly
  4. Verify margins and alignment
  5. Confirm logo and graphics appear properly
  6. Test with different paper sizes if needed

Alternative: Export to PDF

If printing continues to be problematic, consider PDF export:

  • More reliable across different systems
  • Better for email distribution
  • Archival purposes
  • No printer driver dependencies

To export:

  1. Open report/invoice
  2. Click "Export" or "Save As"
  3. Choose PDF format
  4. Select destination folder
  5. Print PDF using any PDF reader

Advanced Troubleshooting

Registry Settings (Windows)

Warning: Editing registry can cause system problems if done incorrectly. Back up registry before making changes.

Reset print settings in registry:

  1. Press Win + R, type: regedit
  2. Navigate to: HKEY_CURRENT_USER\Software\TurboCASH\Printing
  3. Delete the Printing key (it will be recreated)
  4. Restart TurboCASH
  5. Reconfigure print settings

Check Application Logs

Review TurboCASH logs for printing errors:

  • Location: C:\Users\[Username]\AppData\Local\TurboCASH\Logs\
  • Look for files: print_errors.log or application.log
  • Search for keywords: "print", "printer", "error"
  • Error codes can help identify specific issues

When to Contact Support

  • Printing works in other applications but not TurboCASH
  • Error persists after trying all solutions
  • Specific error codes appear in logs
  • Need custom template development
  • Printer model has known compatibility issues
