How do I install TurboCASH on Windows?

Last updated: November 17, 2025 | Category: Installation & Setup

Overview

TurboCASH is an open-source accounting application that requires a database backend (MySQL or PostgreSQL). This guide walks you through the complete installation process on Windows systems.

System Requirements:
  • Windows 7 or later (Windows 10/11 recommended)
  • 2 GB RAM minimum (4 GB recommended)
  • 500 MB free disk space for application
  • Additional space for database (varies by usage)
  • Screen resolution: 1024x768 or higher

Step 1: Download TurboCASH

  1. Visit the official TurboCASH GitHub releases page
  2. Download the latest Windows installer (TurboCASH-Setup-X.X.X.exe)
  3. Verify the file size and checksum if provided
  4. Save the installer to a convenient location (e.g., Downloads folder)

Step 2: Install Database Server

TurboCASH requires a database backend. You can choose either MySQL or PostgreSQL.

Option A: Installing MySQL

  1. Download MySQL Community Server from the official MySQL website
  2. Run the MySQL installer
  3. Choose "Developer Default" or "Server only" setup type
  4. Set a strong root password (remember this!)
  5. Configure MySQL to run as a Windows Service
  6. Complete the installation wizard

Recommended settings:

  • Port: 3306 (default)
  • Character Set: utf8mb4
  • Authentication: Use Strong Password Encryption

Option B: Installing PostgreSQL

  1. Download PostgreSQL from the official PostgreSQL website
  2. Run the PostgreSQL installer
  3. Accept the default installation directory
  4. Set a strong password for the postgres superuser
  5. Keep the default port (5432)
  6. Complete the installation

Step 3: Create TurboCASH Database

For MySQL:

Open MySQL Command Line Client or MySQL Workbench and run:

CREATE DATABASE turbocash_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'turbocash_user'@'localhost' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON turbocash_db.* TO 'turbocash_user'@'localhost';
FLUSH PRIVILEGES;

For PostgreSQL:

Open pgAdmin or psql command line and run:

CREATE DATABASE turbocash_db;
CREATE USER turbocash_user WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE turbocash_db TO turbocash_user;

Step 4: Install TurboCASH

  1. Right-click the downloaded installer and select "Run as Administrator"
  2. If Windows SmartScreen appears, click "More info" then "Run anyway"
  3. Accept the GNU GPL license agreement
  4. Choose installation directory (default: C:\Program Files\TurboCASH)
  5. Select components to install:
    • ✓ Core Application (required)
    • ✓ Documentation (recommended)
    • ✓ Sample Data (optional, useful for testing)
  6. Create Start Menu shortcuts (recommended)
  7. Click "Install" to begin installation
  8. Wait for the installation to complete

Step 5: Initial Configuration

When you first launch TurboCASH:

  1. The Setup Wizard will start automatically
  2. Select your database type (MySQL or PostgreSQL)
  3. Enter database connection details:
    • Server: localhost
    • Port: 3306 (MySQL) or 5432 (PostgreSQL)
    • Database Name: turbocash_db
    • Username: turbocash_user
    • Password: (the password you created earlier)
  4. Click "Test Connection" to verify settings
  5. If successful, click "Next" to initialize the database
  6. Create your first company profile
  7. Set up basic accounting preferences

Step 6: Verify Installation

Check that everything is working correctly:

  • TurboCASH application launches without errors
  • You can log in with your credentials
  • Database connection is successful
  • Main menu and modules are accessible
  • Create a test transaction to verify functionality

Troubleshooting Common Installation Issues

Installer Won't Run

Solution:
  • Ensure you're running as Administrator
  • Temporarily disable antivirus software
  • Check Windows Event Viewer for error details
  • Verify the installer isn't corrupted (check file size/checksum)

Database Connection Fails

Solution:
  • Verify database service is running (check Services.msc)
  • Double-check username, password, and database name
  • Test connection using MySQL Workbench or pgAdmin
  • See Database Connection Errors FAQ

Missing .NET Framework or Dependencies

Solution:
  • Install .NET Framework 4.7.2 or later from Microsoft
  • Install Visual C++ Redistributables if prompted
  • Run Windows Update to ensure system is current

Post-Installation Tasks

  • Set up regular database backups (see Backup FAQ)
  • Configure user accounts and permissions
  • Import your chart of accounts
  • Set up company information and preferences
  • Configure tax/VAT settings for your region
  • Customize invoice templates
Security Recommendations:
  • Use strong, unique passwords for database accounts
  • Keep TurboCASH and database software updated
  • Enable Windows Firewall
  • Regular backups to external media or cloud storage
  • Restrict database access to localhost unless needed
